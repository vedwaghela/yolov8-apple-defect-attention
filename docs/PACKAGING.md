# Packaging provenance

This is a publication copy of the completed study, not a new experiment. The original private workspace remains unchanged.

- Experimental Python source files are byte-for-byte copies.
- Published JSON paths use ${PROJECT_ROOT} instead of the original user's local folders. No numerical results are changed. Local paths in text settings are normalized in the same way.
- scripts/setup_local.py restores working records and verifies the original split without creating new memberships.
- Historical checkpoint hashes refer to excluded original weights. Original source and manifest hashes refer to the original files, not path-normalized JSON or regenerated local configurations.
- Only final paper and slides are included. Course instructions, private emails, previous drafts, source-dataset copies, logs, caches and trained weights are omitted.
- MANIFEST_SHA256.json records the files in this publication package, excluding itself.
